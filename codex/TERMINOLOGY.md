# Naming and terminology

- **Adrian Vale:** Earth alias. **Kael-Varr:** Kryptonian name. Use the alias in public dialogue unless a disclosure is intended.
- **Adaptation Talent:** author/reference term. In-world use of that exact label requires established knowledge; no HUD or narrator-like voice is implied.
- **Sealed / released:** access states. “Human-level access” must not be paraphrased into “he was never stronger than an ordinary human.”
- **Red sun / red kryptonite:** different concepts. The chosen history concerns red-sun development; do not substitute red kryptonite to explain temperament.
- **Fort Rozz:** prison background. Being a former prisoner is not membership in an antagonist faction.
- **Canon / design / draft / accepted:** different provenance states. None is interchangeable with “the assistant wrote it once.”
- **Episode number:** provider/order dependent for the first season's swapped pair; use title plus the stored broadcast index.
- **Earth age:** separate apparent, biological, subjective and elapsed chronological age. Do not add Phantom Zone years as lived experience without a rule.
- **Power order:** the Talent's Adaptive Order is not a combat ranking. None has been assigned to Adrian.

Use consistent spellings in files. Do not import cultivation ranks, spirit rings, MCU core stages or a System skill-percentage ladder.
