## Complete core foundation and codex package

This is the populated story-bible workspace for the chosen **Supergirl television-series** fan fiction. It contains actual character, relationship, world, power, technology and timeline files—not just a list of documents to create later.

**Authority:** your decisions remain fixed. Added history and technical details are clearly marked **working designs**, not invented user approvals or verified television canon. The current accepted chapter state is always in [STATUS_PANEL](foundation/STATUS_PANEL.md).

## 8. Tools and verification

```bash
python3 tools/render_codex.py
python3 tools/render_state.py
python3 tools/run_all.py
python3 tools/verify.py --ship 1
```

The first commands regenerate views and check the project. The last checks release readiness of the existing chapter separately; it must not be confused with foundation integrity. See [VALIDATION](audits/VALIDATION.md) for actual executed results.

The extended checks include entity references, relationship and knowledge state, proposed-versus-confirmed ability claims, chronology dependencies/cycles, approval receipts, episode-order integrity and stale generated ledgers. They do not replace literary judgment or source verification.
