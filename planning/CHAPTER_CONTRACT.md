# Chapter contract — from foundation to delivery

## Before prose
Select a bounded source span and original OC turn. Read relevant local designs and distinguish approved facts from proposals. Record viewpoint, time, place, available information, access state, stakes and end condition. Source verification must be described honestly: recap, direct source or unresolved.

## While drafting
Use original dialogue and transformative fan-fiction scenes, not an episode transcript replacement. Canon characters retain private viewpoints and independent motives. Give Adrian a real action with consequences. Do not reveal knowledge he has not acquired or state power numbers that have not been established.

## After prose
Perform actual canon/continuity/power/knowledge/character/prose review against the saved file. Record specific findings and the reviewed hash. Update coverage and proposed changes; do not advance accepted state. Run structural/domain checks and self-tests where appropriate. A failed release gate is not permission to change the gate’s meaning.

## Delivery bundle
Chapter file + coverage + review + proposed state deltas + executed validation + handoff. Acceptance is a separate recorded step. Once accepted, update manifest, detailed ledgers, generated views and hashes together. No chat-only chapter with missing files.
